# Role-separated review evidence

> **NOT FOR PRODUCTION — MOCK PROVIDERS ONLY**

Gate and pull-request review records live here. Each record must identify the implementation author role, a different Evidence/Blue/Red reviewer role, the exact commit or artifact reviewed, reproducible commands, observed results, unresolved findings, and the reviewer conclusion.

Agent review is engineering evidence and must never be described as independent professional certification. Changes involving money, authorization, activation, irreversible service operations, Provider permissions, migrations, or backup/restore cannot count the author as their required reviewer.
