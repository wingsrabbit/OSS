# Laboratory limitations

> **NOT FOR PRODUCTION — MOCK PROVIDERS ONLY**

This file is a mandatory release-claim boundary from the first repository revision. It will be expanded with measured evidence during G9.

- No real payment, refund, cryptocurrency, provisioning, verification, mail, tax, anti-abuse, or vendor Provider has been implemented or validated.
- No real customer, production secret, production dataset, or legacy-system object is permitted in the laboratory.
- Mock and conformance results cannot prove real-provider correctness, payment compliance, tax compliance, privacy compliance, or operational fitness.
- The planned two-host, single-region laboratory is not high availability and is not a production disaster-recovery design.
- Laboratory RPO/RTO measurements will describe only the tested synthetic environment and are not a customer SLA.
- A future production path still requires real Provider projects, independent professional security assessment, legal and compliance decisions, a customer Beta, production disaster recovery, and separately authorized production gates.
- This project must not be described as ready to replace WHMCS or accept real business unless those later gates are separately authorized and passed.
